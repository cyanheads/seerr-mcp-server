# 0.2.0 — 2026-10-28

## Added

- **`seerr-guide` skill** published as an MCP resource (`skill://seerr-guide/SKILL.md`, plus the `skill://{+path}` template and the `io.modelcontextprotocol/skills` extension). It covers availability vs 4K tracks, what `openRequest` reports, season and Specials requests, who owns server-made requests, the confirmation round, and what a refused submit means.
- **Agent Plugins manifest:** root `plugin.json` / `mcp.json` pair (template from mcp-ts-core 0.13.18).

## Changed

- **Tool arguments (mcp-ts-core 0.13.14):** a number spelled as a string, or `null` at an optional key, is repaired instead of rejected. Verified: `limit: "5"` on `seerr_search_media`, `tmdbId: "200"` on `seerr_get_media`, and `take: null` on `seerr_list_requests` were rejected by 0.1.5 and now pass validation.
- **Tool error text (mcp-ts-core 0.13.16):** the `Error:` and `Recovery:` text and the `reason` of a tool error in `content[]` are Markdown-escaped; `structuredContent` is unchanged.
- **Enrichment trailer (mcp-ts-core 0.13.18):** string values such as the search query echo render as code spans.
- **Startup and shutdown (mcp-ts-core 0.13.16):** an out-of-range framework env value (a fractional or negative count, an out-of-range timer) stops startup with the variable named. HTTP shutdown answers `503` with `Retry-After` while draining.
- **Packaging:** the bundle cleaner keeps the MCP SDK's `dist/ext/skills/` runtime while stripping package-root agent docs, and also strips node-gyp build output and build-only package files; `.mcpbignore` lines are root-anchored; npm, Docker and the `.mcpb` ship `skills/`. Local port of the cleaner fix tracked as [cyanheads/mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794).
- **Docs:** README Skills section; `docs/design.md` status-code ranges corrected to request 1–5 / media 1–7.

## Fixed

- **Upstream text in `content[]`:** titles, overviews, season and episode names, air dates and timestamps, requester, profile and service names, and paths from Seerr now render literally when they contain Markdown characters; `structuredContent` is unchanged.
