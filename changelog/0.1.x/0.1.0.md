# 0.1.0 — 2026-06-13

Initial release. A workflow MCP server over a self-hosted Seerr (Jellyseerr/Overseerr) instance: search → confirm the TMDB-backed title → check availability/request state → create a guarded request that Radarr/Sonarr act on. Read + guarded-request only; admin-scope endpoints (approve/decline, retry, edit/delete, media/file deletion, user/settings/sync) are excluded by design.

## Added

- **`seerr_search_media`** — title disambiguation over `GET /search`; filters to movie/TV, normalizes hits, decodes `mediaInfo` availability when tracked. Required first step before requesting.
- **`seerr_get_media`** — movie/TV detail with availability, existing-request context, and per-season summary or one season's episode list.
- **`seerr_list_requests`** — recent requests with status/type/requester filters; decoded statuses, echoed filters, PII-redacted requester.
- **`seerr_request_media`** — the guarded write. Defaults to `mode:preview` (resolve + validate, no write); `mode:request` submits only after a `ctx.elicit` confirmation, with `destructiveHint` as the non-interactive fallback. 4K/seasons/partial-request validation runs locally against cached `/settings/public` before any POST.
- **`seerr_request_status`** — single request lifecycle: decoded request + media status, requester, routing summary, and a state-tuned next-step hint.
- **`seerr_service_options`** — Radarr/Sonarr services, default quality profiles, and instance capability flags (4K, partial requests, specials, media server). Filesystem paths redacted unless `includePaths`.
- **`seerr://request/{requestId}`** resource — read-once request summary mirroring `seerr_request_status`.
- **Status decoding** — request (1=pending, 2=approved, 3=declined, 4=failed, 5=completed) and media (1=unknown, 2=pending, 3=processing, 4=partially_available, 5=available, 6=blocklisted, 7=deleted) statuses decoded everywhere as `{ raw, label }`, including the separate `status4k`; unrecognized codes degrade to `{ raw, label: 'unrecognized' }`.
- **Mandatory PII/infra redaction** (`normalizers.ts`) — a single choke point projects both `requestedBy` and `modifiedBy` User objects to `{ id, displayName }` and drops operator email, Plex/Jellyfin tokens, `jellyfinUserId`, internal `serviceUrl`/`serviceUrl4k`, filesystem paths (`activeDirectory`, `activeAnimeDirectory`, root-folder paths), `vapidPublic`, and `plexClientIdentifier` before any tool output.
- **Error normalization** — Seerr's HTTP 500 `Unable to retrieve movie.` maps to `media_not_found`; HTTP 404 `Request not found.` maps to `request_not_found`; both carry search-recovery hints.

## Config

- `SEERR_BASE_URL` (required) — instance base URL; the service appends `/api/v1`.
- `SEERR_API_KEY` (required) — sent as the `X-Api-Key` header.
- `SEERR_REQUEST_TIMEOUT_MS` (default 15000) — per-request HTTP timeout.
