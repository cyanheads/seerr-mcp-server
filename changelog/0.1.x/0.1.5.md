# 0.1.5 — 2026-10-07

## Changed

- **Framework input and errors:** adopt integer-to-string repair and field-path validation hints from mcp-ts-core 0.13.9, error request IDs from 0.13.10, and removal of framework-added `rootCause` from 0.13.13.
- **Packaging:** refresh Docker dependency stages, registry launch metadata, bundle exclusions, framework scripts/skills and runtime documentation. Build/package-manager pins move to Bun 1.4.2; minimums remain Bun 1.4.0 and Node 24.

## Fixed

- **Request creation:** stop automatic retries of non-idempotent `POST /request`; required reads retain their retry policy ([#11](https://github.com/cyanheads/seerr-mcp-server/issues/11)).

## Security

- **Media confirmation:** bind consent to a single-use caller/payload record; missing, mismatched, expired or replayed records ask again ([#10](https://github.com/cyanheads/seerr-mcp-server/issues/10)). Concurrent redemption is exclusive within one process; cross-instance read-and-delete is not atomic.
